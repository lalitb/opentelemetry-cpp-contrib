Run (Windows, MSVC, CMake)
--------------------------
Check out opentelemetry-cpp v1.30.0 separately. From this benchmark directory:

  cmake -S . -B build -A x64 -DOPENTELEMETRY_CPP_ROOT=C:\path\to\opentelemetry-cpp
  cmake --build build --config Release --target geneva_etw_benchmark

Run in an elevated PowerShell to enable ETW and verify captured events:

  powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1

Results
--------
Single thread, three attributes, 64-byte log body. Median batch-average time
per record/span across seven batches of 10,000 calls after 1,000 warm-up calls.
Windows 11, AMD EPYC 7763 (16 logical processors exposed), MSVC x64 Release.

Operation                       Time
Log emit only                   6.40 us
Log create + populate + emit     6.98 us
Span end only                   7.24 us
Span start + attributes + end    9.27 us

ETW capture: 284,000 expected events captured, zero lost.
Raw timings and capture verification are written to results\.
