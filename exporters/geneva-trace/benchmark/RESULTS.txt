Run (Windows, MSVC, CMake)
--------------------------
Check out opentelemetry-cpp v1.30.0 separately. From this benchmark directory:

  cmake -S . -B build -A x64 -DOPENTELEMETRY_CPP_ROOT=C:\path\to\opentelemetry-cpp
  cmake --build build --config Release --target geneva_etw_benchmark

Run in an elevated PowerShell to enable ETW and verify captured events:

  powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1

Optional Span::End breakdown (instruments build-directory header copies only):

  cmake -S . -B build -DGENEVA_ETW_BREAKDOWN=ON
  cmake --build build --config Release --target geneva_etw_breakdown
  powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -Breakdown

Optional Google Benchmark (one span lifecycle case, no stage probes):

  cmake -S . -B build -DGENEVA_ETW_GOOGLE_BENCHMARK=ON
  cmake --build build --config Release --target geneva_etw_google_benchmark
  powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -GoogleBenchmark

Results
--------
Single thread, three attributes, 64-byte log body. Median batch-average time
per record/span across seven batches of 10,000 calls after 1,000 warm-up calls.
Windows 11, AMD EPYC 7763 (16 logical processors exposed), MSVC x64 Release.

Operation                       Time
Log emit only                   6.40 us
Log create + populate + emit     6.98 us
Span end only                   7.24 us
Span start + attributes + end    9.27 us

ETW capture: 284,000 expected events captured, zero lost.
Raw timings and capture verification are written to results\.

Span::End stage breakdown (same workload, separate instrumented run)
------------------------------------------------------------------
Stage                                  Time/span
TLD metadata + payload encoding         1.71 us
ETW write                               1.60 us
Two timestamps + field assignment       1.26 us
Attribute copying                      0.83 us
Cleanup + other bookkeeping             0.68 us
IDs + envelope fields                   0.59 us
Duration/kind/status fields             0.45 us
Instrumented total                      7.13 us

Largest median: TLD encoding; ETW write is close (0.64-1.81 us across batches).
Empty probe sequence: 0.225 us/span, not subtracted. Stage times include their
allocations, not allocator-only cost. No context attach/detach is exercised.
ETW capture: 71,000 expected events captured, zero lost. Raw data: results\breakdown\.

Google Benchmark v1.9.4: full span lifecycle
------------------------------------------
StartSpan + three attributes + End/ETW write + destruction: median 9,024 ns/span.
Wall-clock time (UseRealTime), seven repetitions of 10,000 spans, with 1,000
untimed warm-up spans per repetition. Provider/source-attribute setup excluded.
ETW capture: 77,000 expected events captured, zero lost.
Raw output and JSON: results\google-benchmark\.
